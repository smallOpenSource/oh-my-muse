# PR Body

리뷰 앞에 작업이 놓일 때, 세션 밖의 리뷰어가 읽는 유일한 산출물이 PR 본문이다. 필요한 것은 이미 paper trail에 다 있다 — 이 스킬은 그것을 조립할 뿐, 확립되지 않은 것을 새로 덧붙이지 않는다. 요약 시각(summary-visual) 규율은 show-me(Humanlayer, Dex Horthy)에서 영감을 받았다.

## Template

붙여넣기용 템플릿:

```markdown
## Summary
<한 줄 주장, 그 다음 주장을 증명하는 최소 시각>

## Evidence
- **Before:** <출력 / 실패한 검사>
  **After:** <출력 / 통과한 검사>

## Reversibility
<Rollback: cheap via <mechanism> | expensive because <reason>>
<Blast radius: one line>
```

## Workflow

### 1. Summary — 한 문장 + 최소 시각

변경 내용을 한 문장으로 말하고, 그 점을 드러내는 가장 작은 시각을 보여준다. 변경에 맞는 시각을 고른다:

- 로직·알고리즘 → 의사코드
- 런타임 제어 흐름 → 호출 트리
- UI 구조 → 컴포넌트 트리
- 파일 책임·넓은 리팩터 → 얕은 파일 트리
- 컴포넌트 상호작용·데이터 흐름 → Mermaid 다이어그램
- 델타 자체 → 변경의 형태를 닮은 diff (컴포넌트, 레이아웃, 호출 트리, 상태 머신)

대부분이 새것이거나, 생략된 맥락이 소유권을 가리거나, 리뷰어가 복사 가능한 목표 형태를 필요로 할 때만 전체 블록을 보여준다. 보통 하나의 시각이면 충분하다 — 모든 형태를 다 쓰지 않는다.

### 2. Evidence — verify 프로토콜의 증거를 소비

`verify` 스킬의 산출(BUILD, TEST, LINT, FUNCTIONALITY 증거, freshness 규칙 계승)을 그대로 쓴다. Before/After 쌍으로 제시: 실패했던 정확한 검사가 통과한 것을 출력 그대로 인용한다. 시각 변경이면 캡처된 스크린샷을 우선한다. **여기서 증거를 재수집하지 않고, verify 패스가 만들지 않은 증거를 주장하지 않는다.**

### 3. Reversibility — diff에 ADR 테스트 적용

launch가 결정에 적용하는 세 질문을 diff 자체에 돌린다: 되돌리기 어려운가? 맥락 없이 놀라운가? 실제 트레이드오프의 결과인가? 세 개 다 아니면 싼 롤백이다 — 어떤 메커니즘으로 되돌리는지 말한다(머지 revert, 플래그 토글). 하나라도 예면 비싼 롤백이다 — 왜 그런지 말한다. 먼저 문(door)을 분류한다: 되돌리기가 싸고 일상적인 two-way door는 되돌리는 법을 이름 붙이는 것 외에 의식이 필요 없다. one-way door는 명시적으로 밝히고, 그 단계를 비가역으로 만드는 것이 무엇인지 말한다. 변경이 ADR을 구현하거나 건드리면 ADR을 링크한다. 마지막은 blast radius 한 줄 — 이 변경이 또 무엇을 움직일 수 있는지.

### 4. Language — 용어

용어는 `GLOSSARY.md`가 있으면 거기서 가져온다(레거시는 `CONTEXT.md`). PR은 세션 밖에서 읽힌다 — 용어집이 세션과 독자가 공유하는 유일한 어휘다.

## Output Contract

- 붙여넣기 가능한 PR 본문
- 본문이 의존한 paper-trail 포인터 (verify 증거, ADR, 스펙)

## Operating Rules

- **트리거**: launch Phase 5(종료) — 플랫폼이 PR로 리뷰하면 완료 보고에 이 스킬로 초안한 PR 본문을 싣는다. PR을 열거나 실질적으로 업데이트하는 모든 세션.
- **재수집 금지**: 증거는 verify에서, 판단 근거는 ADR·스펙에서 가져온다. 이 스킬에서 새로 만들지 않는다.
- **런타임 구동 한계**: 이 환경에는 라이브 브라우저가 없어 런타임을 직접 구동해 스크린샷을 확보할 수 없다. 사용자가 업로드한 스크린샷을 사용하고, 직접 구동이 필요하면 부모 에이전트에 브라우저 위임을 요청한다.
- **리뷰어는 세션 밖의 사람**이라고 가정하고 쓴다 — 세션 맥락에 기대지 않는다.
