# Remember

## Purpose

- 세션 중에 발견한 유용한 지식을 채팅 히스토리에 묻어두지 않고, 적절한 메모리 표면에 승격(promote)한다.

## 메모리 표면 (Memory Surfaces)

| 표면 | 용도 | 이 환경의 매핑 |
|------|------|---------------|
| **프로젝트 메모리** | 내구성 있는 팀·프로젝트 지식 | `MEMORY.md` / `~/memory/` 일일 노트 (메인 에이전트의 메모리 흐름을 통해 기록) |
| **Notepad priority** | 다음 턴을 위한 짧고 신호 강한 컨텍스트 | 이 환경에 notepad 없음 → 대안: 채팅 컨텍스트에 유지하거나 `~/workspace/` 임시 노트 파일 |
| **Notepad working** | 임시 활성 세션 노트 | 이 환경에 notepad 없음 → 대안: `~/workspace/` 스크래치 파일 (세션 종료 후 정리) |
| **Docs / AGENTS / CLAUDE 파일** | 정말로 속해야 할 때만 쓰는 내구성 지침·컨벤션 | 저장소 규칙 파일(`AGENTS.md` 등)에 반영 |

## Workflow

1. 세션의 관련 발견을 수집한다.
2. 각 항목을 분류한다:
   - 내구성 있는 프로젝트 사실
   - 임시 작업 노트
   - 운영자 선호·지침
   - 중복 / 오래된 / 충돌하는 정보
3. 각 항목의 최적 목적지를 제안한다.
4. 적절한 메모리 표면에만 쓰고 갱신한다.
5. 정리해야 할 중복·충돌을 지적한다.

## Output Contract

- 무엇을 저장했는지
- 어디에 저장했는지
- 발견된 중복·충돌

## Operating Rules

1. **한 저장소에 몰아넣지 않는다** — 표면별로 목적이 다르다.
2. **내구성 팀 지식은 프로젝트 메모리로** — 단기 컨텍스트는 notepad 대안(임시 파일/채팅 컨텍스트)으로.
3. **간결하고 실행 가능하게** — 항목은 짧고 actionable하게.
4. **불확실하면 불확실하다고 표시** — 사실인 것처럼 저장하지 않는다.
5. **메모리 파일 직접 편집 주의** — `MEMORY.md`·`~/memory/` 일일 노트는 메인 에이전트의 메모리 정책에 따라 관리된다. 직접 파일을 고치기보다 기록이 필요한 내용을 메인 에이전트에게 전달한다.
6. **Notepad 기능 없음** — 원본의 notepad priority/working 표면은 Claude Code/OMC 전용이다. 대안으로 채팅 컨텍스트 유지 또는 `~/workspace/` 임시 노트 파일을 사용하고, 한계를 명시한다.
7. **명령어 흡수**: 원본 `/oh-my-claudecode:remember` 슬래시 커맨드는 단순 디스패치 래퍼였으므로, 이 스킬의 채팅 트리거("이거 기억해줘" 등)로 대체된다.
