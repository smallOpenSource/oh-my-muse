# harness-factory: 에이전트 팀 아키텍처 팩토리

## Purpose

도메인을 한 줄로 받아 **전문 서브에이전트 팀**(각 에이전트 + 그 에이전트가 쓸 스킬 묶음)을 설계·스폰·운용하는 **메타 스킬**이다. 원본(banker의 revfactory/harness)은 Claude Code 플러그인이지만, 이 환경(Muse)에서는 설치형 플러그인이 아니라 **방법론 + subagent.spawn 스폰 규약**으로 동작한다. 이미 설계된 팀이 있으면 갱신·재확인만 한다(멱등). 답변은 한글.

## Workflow

### 0. 감지·감사 (먼저, 추정 금지)

- 작업 목표와 도메인을 한 줄로 확정한다.
- 이미 비슷한 전문 에이전트/스킬이 있으면 신규 생성이 아니라 확장·유지보수로 다룬다.
- 병렬 subagent 스폰이 가능한 환경인지 확인한다(부모 에이전트에 `subagent.spawn` 가용).

### 1. 모드 결정 (team / subagent / hybrid)

- 2+ 에이전트 + 실시간 상호통신(교차검증·발견 공유)이 가치를 더하면 → **team** (subagent.spawn으로 병렬 스폰 후 집계).
- 단일 작업·독립 병렬·결과만 반환이면 → **subagent**(경량·토큰효율).
- 공식 비용지침: **순차·동일 파일 편집·의존성 많은 작업은 단일/순차 subagent가 유리**하다. "2+면 팀 기본"이라는 관성에 팀이 정말 필요한지 재확인하는 게이트를 둔다.

### 2. 6개 아키텍처 패턴 (1줄)

- **Pipeline** (순차 의존): n 출력이 n+1 입력.
- **Fan-out/Fan-in** (병렬+집계): 팀모드가 가장 자연스럽다.
- **Expert Pool** (라우팅 택1): 라우터가 입력 분류 후 전문가 하나 호출, subagent 적합.
- **Producer-Reviewer** (생성·검증): 재시도 캡 2-3(무한루프 방지).
- **Supervisor** (동적 분배): 중앙이 런타임 조건으로 워커 배정.
- **Hierarchical** (재귀 위임): 깊이 ≤ 2 (3+는 지연·컨텍스트 손실). 이 환경의 서브에이전트는 depth 제한이 있으므로(depth 2/2면 추가 스폰 불가) 깊이 계획 시 반드시 확인.

### 3. 팀 스폰 (subagent.spawn)

각 멤버에게 줄 프롬프트는 간결하게: **역할 + 입력 + 산출물 계약 + 금지사항**. 공통 규칙:

- 팀 규모 **3-5명** (집중된 3명 > 분산된 5명).
- 팀 실행은 단일세션 대비 **약 7× 토큰** (원본 공식 수치) — 규모·모델·종료 가드를 둔다.
- 작업 완료 즉시 종료한다.
- 파일 편집이 겹치면 순차로 바꾼다(동일 파일 동시 편집 금지).

### 4. 리스크 고지

- **무증상 단일화**: 팀 스폰이 실패했는데 에러 없이 단일 흐름으로 진행되면 패턴이 소리 없이 깨진다. 스폰 결과를 확인하고, 팀원이 실제로 돌았는지 검증한다.
- **부작용(read-only 아님)**: 팀 실행은 프로젝트에 파일을 직접 생성한다(에이전트/스킬 산출물·중간 파일). 기존 파일 충돌 처리와 산출물 위치를 사전에 정한다.

## Output Contract

4-field 보고: **감지**(도메인·기존 산출물 흔적) · **설계**(선택 패턴·팀 구성·역할) · **스폰**(subagent.spawn 실행 결과) · **검증**(산출물 존재·팀 실제 동작 여부). 실패·불명확은 정직 보고(가짜 성공 금지).

## Operating Rules

- **원본의 Claude Code 설치 절차**(`/plugin marketplace add revfactory/harness`, `/plugin install harness@harness-marketplace`)는 Claude Code 환경 전용 참고 정보다. 이 환경에서는 설치할 플러그인이 없으므로 그 절차를 그대로 따라 하지 않는다.
- **experimental flag 영속화**(`CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS`)는 Claude Code 전용이다. 이 환경에 해당하지 않는다.
- **Codex 전용 경로**(meta-harness Python 인스톨러, 파일 handoff)는 생략한다. Codex 환경을 대상으로 작업할 때만 원본 문서를 참조한다.
- 이 환경의 팀 스폰은 **`subagent.spawn`**이 유일한 메커니즘이다. 원본 문서의 `TeamCreate`/`TeamDelete` 같은 팀 프리미티브 호출 예시는 Muse 환경에 매핑되지 않는다.
- 상류 harness의 심층 자료(패턴 카탈로그·오케스트레이터 템플릿·팀 예시)는 필요하면 웹에서 원본 저장소를 참조하되, verbatim 복사하지 않는다.
- 비용 7× 가드 없이 팀을 돌리지 않는다.
