# AI Slop Cleaner

## Purpose

동작은 바꾸지 않고 AI 생성 코드의 슬롭을 정리한다. 목표는 단순화·정리이지 새 기능 전달이 아니다. 원본의 `/oh-my-claudecode:ai-slop-cleaner <target> [--review]` 사용법은 채팅 트리거로 대체한다 ("deslop 해줘", "슬롭 청소해줘", "<타깃> deslop"). 파일 목록을 명시해 범위를 한정할 수도 있다 ("<file-a> <file-b> deslop").

**사용**: deslop/anti-slop/AI slop 명시 요청, 소음·반복·과도 추상화 코드 정리, 구현 후속의 중복·데드코드·래퍼·경계 누수·약한 커버리지 정리, `--review` 리뷰어 전용 패스 요청.
**미사용**: 새 기능·제품 변경 위주, 전면 재설계, 일반 리팩터 (단순화 의도 없음), 테스트·검증 계획으로 보호할 수 없을 만큼 동작이 불분명.

## Workflow

1. **동작 보호 먼저** — 무엇을 그대로 둬야 하는지 식별한다. 편집 전 가장 좁은 회귀 테스트를 추가·실행한다. 테스트가 먼저 올 수 없으면 검증 계획을 편집 전에 명시적으로 기록한다.
2. **코드 전에 정리 계획 작성** — 요청된 파일·기능 영역으로 범위를 한정한다. 제거할 구체적 스멜(냄새) 목록을 만든다. 가장 안전한 삭제부터 위험한 통합 순으로 정렬한다.
3. **편집 전 슬롭 분류** — **중복**(반복 로직, 복사-붙여넣기 분기) / **데드코드**(미사용 코드, 도달 불가 분기, 디버그 잔재) / **불필요 추상화**(통과 래퍼, 투기적 간접층) / **경계 위반**(숨은 결합, 잘못된 층의 import·부작용) / **테스트 부족**(보호되지 않은 동작) / **UI 기본값**(검토 안 된 느낌의 AI 기본 시각 패턴)
4. **스멜별 패스 1회씩** — Pass 1: 데드코드 삭제 → Pass 2: 중복 제거 → Pass 3: 네이밍·에러 처리 정리 → Pass 4: 테스트 보강. 각 패스 후 대상 검증을 재실행. 무관한 리팩터를 같은 편집 묶음에 넣지 않는다.
5. **품질 게이트** — 회귀 테스트 그린 유지. 해당 영역의 lint·타입체크·단위/통합 테스트 실행. 있는 경우 기존 정적·보안 검사도 실행. 게이트 실패 시 억지로 밀지 말고 고치거나 위험한 정리를 되돌린다.
6. **증거 밀도 높은 보고** — 변경 파일 / 단순화 내용 / 동작 보호·검증 실행 / 남은 리스크를 항상 보고한다.

### 리뷰 모드 (`--review` 상당)

정리 작업 초안이 나온 뒤의 리뷰어 전용 패스다. 같은 패스가 작성과 셀프 승인을 겸하지 않는다.

1. 먼저 파일을 편집하지 않는다.
2. 정리 계획·변경 파일·회귀 커버리지를 검토한다. 특히: 남은 데드코드·미사용 export, 통합했어야 할 중복 로직, 경계를 흐리는 불필요 래퍼/추상화, 보호되지 않은 동작의 테스트 누락, 의도 없이 동작이 바뀐 정리를 본다.
3. 필수 후속 조치가 담긴 리뷰어 판정을 내리고, 수정은 별도 작성자 패스로 넘긴다.

## Output Contract

- 변경 파일 목록
- 단순화 내용 (무엇을 삭제·통합했는지)
- 동작 보호 / 검증 실행 결과 (테스트 명령·결과)
- 남은 리스크

## Operating Rules

- 사용자가 명시적으로 요청하지 않는 한 동작을 보존한다.
- 삭제 우선: 추가보다 삭제를, 기존 유틸·패턴 재사용을 새 도입보다 우선한다.
- 사용자 명시 요청 없이는 새 의존성을 추가하지 않는다.
- diff는 작고 되돌릴 수 있게, 스멜 단위로 유지한다.
- 새 사용자 지시는 이전의 상충하지 않는 제약과 함께 로컬 범위 업데이트로 취급한다.
- 한계와 대안: 원본의 Ralph 연동(세션 변경 파일 범위 자동 전달)은 Ralph 워크플로가 이식되지 않았으므로, 호출자가 파일 리스트를 명시하면 같은 회귀 안전 워크플로를 그 범위에 적용한다. 범위 외 정리를 조용히 확장하지 않는다.
- UI 검토 체크리스트(원문 유지): 한국어 본문 11~12px 경계(밀집 데이터 예외 제외 최소 14px 권고), 표면·로고·배경·카드·아이콘 남발 박스 섀도우(높이·상호작용을 명확히 할 때만 유지), 제목이 이미 전달하는 반복 eyebrow/title/description/<p> 채우기, 제품 보이스가 아니면 일반적인 이모지 배지, 브랜드 근거 없는 AI 기본 파랑/보라 팔레트(특히 #3B82F6류), 지나치게 균일한 3~4열 그리드, 브랜드 언어가 아닌 극단적 그라디언트. 의도적 브랜드·접근성·밀도 선택은 근거가 있으면 유지한다.
